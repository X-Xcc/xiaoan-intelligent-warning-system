# 下线执法办案系统设计

## 目标

从小安智能预警系统中完整移除“执法办案系统”：用户不可在导航或平台首页进入，`/case` 不再解析为案件工作台，平台总览接口也不再声明该业务系统。

## 范围

- 删除前端导航项、首页业务入口和 `case` 路由映射。
- 删除案件工作台页面及其专属验证逻辑。
- 从平台首页演示数据和 `/api/platform/overview` 的目录、业务系统、工作区、业务流转展示数据中移除案件系统。
- 保留其他模块仍使用的案件统计字段、事件存储和通用训练内容。
- 不删除训练目录中“执法办案安全”等课程术语，也不删除底层案件分析能力。

## 方案

以现有单页路由为边界进行删除。`DashboardApp` 继续作为唯一导航和页面分发入口；删除 `case` 后，未知路径（包括 `/case`）由 `viewForPath` 回退到平台总览。平台接口只返回仍在门户展示的业务系统和数据目录，避免前后端出现孤立的案件入口。

## 验证

- 导航测试断言不包含 `case`，且保留其他模块原有顺序。
- 路由测试断言 `/case` 回退到 `platform`，且不存在 `routePath('case')`。
- 页面源码回归测试断言不再包含案件工作台入口和页面标记。
- 运行 dashboard 单元测试、TypeScript/Vite 构建和工作区浏览器验证脚本。
