# 步态分析下一步按钮设计

## 目标

在身份检索详情弹窗的步态分析面板底部增加“下一步”按钮。按钮位于操作栏右侧，点击后直接进入统一的身份分析工作台 `/identity-search`。

## 设计

- 保留左侧的“暂停”和“重置 GEI”按钮。
- 将速度滑块、FPS 信息和“下一步”组织为右侧操作组，使速度控件相对当前布局向左收拢。
- “下一步”使用现有 `ui-button primary` 样式并带 `ArrowRight` 图标。
- 导航通过现有 `routePath('identity-search')` 和 `popstate` 机制完成，不新增路由或状态。
- 小屏下操作组允许换行，按钮保持可点击且不挤压速度滑块。

## 组件与数据流

`GaitAnalysisPanel` 接收一个新的 `onNext` 回调；`ContactRecordModal` 将该回调连接到详情弹窗当前的导航上下文；`ContactReviewPage` 使用现有应用导航能力，将目标路径切换为身份检索页面。

## 错误处理

不新增网络请求或异步流程。若导航回调未提供，组件仍应保持现有分析控件可用；默认调用方会提供统一导航回调。

## 验证

- 增加测试，确认步态分析组件暴露“下一步”操作并连接身份检索路径。
- 运行 dashboard 构建与相关 Node 测试。
- 在本地浏览器确认按钮位置、响应式布局和点击后的 URL/页面标题。
