# 备勤训练演示模式设计

## 目标

在现有公安大数据与 AI 平台的 `/duty-plan` 中新增一条适合现场汇报和录屏的全屏演示链路：A1 勤务态势大屏、A2 靶向训练清单、A3 AI 动捕考核。保留既有训练任务、评分、教官复核和档案能力作为演示结束后的真实业务承接。

## 入口与范围

`/duty-plan` 默认显示演示模式。现有的训练目录与五步训练执行闭环保留，作为 A3 结束后进入的训练执行页。B1 接警工单不纳入本次改动，仍属于 `/command`。

页面采用深色公安指挥中心视觉，不使用营销式卡片堆叠、渐变装饰球或操作说明文字。现有后端训练 API 继续作为任务、评分、复核及档案数据来源；态势图和动捕画面可使用脱敏样例数据与演示用预览素材，并清楚保持“样例/可复核建议”的业务边界。

## 隐形快捷键

全局 `Shift + Space` 是演示推进器，页面不展示键帽提示、快捷键标签或说明文案。

- A1 首次触发：显示短暂声波与“画像生成”状态，约 500ms 后展开环图、热力图、警量曲线和训练横幅。
- A2：每次触发完成当前未完成科目；卡片出现勾选、绿边和完成状态。三个科目均完成后自动转入 A3。
- A3：每次触发依次显示一项评分；三项评分完成后落下“合格”红章，并将现有训练评估置为待教官复核。
- 输入框、下拉框、视频控制器或修饰键组合正在被浏览器使用时不劫持该事件。

## A1 勤务态势大屏

占满内容视口，采用三栏结构：左 25% 为警情类型环图；中 50% 为夜市平面热力图与人流方向；右 25% 为 20:00–23:00 的分时段警量柱状曲线。底部为横向滚动训练推送。

- 环图以“滋事纠纷 41%”“手机扒窃 28%”“其他”“可疑物品 4%”为脱敏样例数据，其中可疑物品使用红色独立强调。
- 热力图以 B 区烧烤摊聚集区为深红热点，并以路径箭头表示人流方向。
- 曲线/柱图突出 20:00–23:00，并标注“高发时段”。
- 首次快捷键触发后动效严格为：环图扇形展开 1 秒，热力波纹扩散 1 秒，底部横幅随后开始滚动。页面在首次触发前保持稳定。
- 横幅文字为“今日靶向训练科目已推送”，顺序为单警装备训练、弱光执法战术训练、防爆先期处置；点击横幅进入 A2。

## A2 靶向训练清单

全屏纵向呈现三张大尺寸训练卡，每张包含科目名称、训练依据、装备清单和达标标准；达标标准在视觉上高于普通正文。

右上角保留完成勾选位。快捷键使当前卡片完成，卡片边框转绿，进度连线与完成计数同步更新。三张卡完成后自动切换 A3。卡片也支持鼠标点击，以便在展示环境中人工恢复或补充操作。

科目映射到既有训练试点任务：单警装备训练、弱光执法战术训练、防爆先期处置。若后端可用，卡片状态与开始/完成接口同步；后端不可用时，演示状态在本地安全回退，不伪造持久化完成结果。

## A3 AI 动捕考核

全屏左右双栏：左侧约 50% 是训练视频预览与动态骨架叠层，右侧约 50% 是三项评分的逐项呈现区。底部横跨页面显示总分与结论印章。

- 评分维度固定为动作规范度、完成用时、协同一致性，并映射既有评估结果。
- 每次快捷键只展示下一项评分，单项进入动画 500ms；最后一项出现后展示总分并播放“合格”红章盖下动画。
- 通过时使用“全体科目达标”作为结果气泡；未达标时改为“存在补训项”，并引导到既有教官复核，不自动归档。
- 骨架叠层是演示视觉，不声称浏览器本地录像已经实时完成真实人体骨骼识别；现有录像采集、评分证据、审计号和教官复核保持不变。

## 数据与状态

新增仅前端的 `showcaseStage`（`a1`、`a2`、`a3`、`handoff`）和每屏进度状态；不更改训练 API 协议。A2 通过现有 `/api/training/tasks` 获取任务，A3 使用现有评分结果。A3 的最终状态跳转至既有教官复核/档案闭环，以保证演示没有绕过人工确认。

## 验收

- `/duty-plan` 打开后是静止的 A1 全屏态势大屏，页面没有快捷键提示。
- `Shift + Space` 可依次完成 A1 生成、A2 三卡、A3 三项评分和结论章；焦点在表单与媒体控件时不触发。
- A1 三栏、底部横幅、A2 三卡及完成联动、A3 动捕视觉/逐项评分/红章均可在桌面 1440px 与移动窄视口正常查看，无文字重叠。
- 不更改训练接口的人工复核与归档边界；前端构建和现有训练前端契约测试继续通过。
