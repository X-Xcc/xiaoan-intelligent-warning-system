# 身份检索 CAM-11 精简设计

## 目标

身份检索页经过步态分析后只关注 `CAM-11`。点击“重新检索”完成后，页面只展示 `CAM-11` 的抓拍记录、点位和时间序列；普通 `/contact-review` 视频筛查页保持现有多机位行为。

## 范围

- 为身份检索模式增加独立的结果过滤边界，固定筛选 `CAM-11`。
- 保留身份检索所需的参考对象、重新检索、扫描进度、抓拍记录和详情查看。
- 隐藏身份检索中无关的行为类型、地点、状态、排序、角色筛选、地图、轨迹碰撞、上传照片提示和复核导出入口。
- 不修改演示数据、不修改普通视频筛查模式、不改变详情弹窗中的步态分析下一步导航。

## 设计

`contact-review.ts` 增加纯函数 `selectIdentitySearchRecords(records, filters)`，先复用现有通用筛选逻辑，再限制 `camera.toLowerCase() === 'cam-11'`。组件在 `showGait` 模式下使用该函数计算结果、统计和选中记录；非身份检索模式继续使用 `selectContactRecords`。

身份检索的筛选表单只保留时间范围和重新检索按钮。结果工作区只保留抓拍记录页签，隐藏地图与轨迹碰撞页签、记录状态栏及额外结果控制。参考对象区域只显示脱敏对象，不提供上传入口。标题操作区隐藏导出按钮。

## 数据流与状态

点击重新检索时，先依据当前时间范围生成身份检索结果，再启动现有扫描阶段。扫描过程中展示匹配进度；完成后结果集合来自 `selectIdentitySearchRecords`，因此所有展示计数和记录卡片都只能来自 `CAM-11`。重置仍恢复初始时间范围和空闲状态。

## 错误处理

日期无效时保留现有表单错误。身份检索结果为空时显示现有空状态。没有新增网络调用或真实身份识别行为。

## 测试

- 纯函数测试确认身份检索过滤后只包含 `CAM-11`，并保留时间等通用筛选。
- 页面源码测试确认身份检索模式隐藏无关控件，同时保留步态详情下一步导航。
- 运行相关 Node 测试和 TypeScript 检查。
