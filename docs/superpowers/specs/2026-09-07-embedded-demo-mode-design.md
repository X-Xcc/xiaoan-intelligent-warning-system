# 原系统嵌入式演示模式设计

日期：2026-09-07
状态：已确认，进入实现

## 目标

在现有“公安大数据与 AI 平台”内直接提供稳定的教学演示效果。系统默认按演示数据和演示状态工作，不新增独立演示站点、独立控制台页面或独立窗口。原左侧导航、页面布局、业务按钮和路径保持不变。

## 交互原则

1. 打开原系统即进入演示态；不要求用户先切换模式。
2. 演示态下，原页面现有按钮触发可重复、可预期的演示结果。
3. 语音、字幕、页面状态和动画由同一个应用状态协调，不能各自计时漂移。
4. 关键节点支持重播、停止、重新开始和跳转；切页时停止旧语音和旧动画。
5. 演示数据不写入真实业务数据库，不触发真实派警、核验或案件变更。
6. 保留现有页面结构，不把独立接处警演示页作为主入口。

## 页面映射

| 现有页面 | 原有交互 | 演示效果 |
| --- | --- | --- |
| 勤务态势 | 生成画像 / 重播画像 | A1 画像动画，瑶瑶“画像已生成” |
| 勤务训练 | 开始训练、提交训练、复核 | A2 卡片状态；完成三科后 A3 评分看板和“全体科目达标” |
| 接处警 | 接警转写、警情摘要、派警建议 | B1 新警情；B2 路线已推送；B3 核验完成；均为演示状态，不写真实业务 |
| 研判相关页面 | 原有查看/确认动作 | C1-C4 的地图、串并、轨迹、链条演示状态 |
| 指挥调度相关页面 | 原有查看/确认动作 | D1-D4 的追踪、调度、结构图和闭环状态 |

## 演示流程

默认预置完整演示数据，支持两种现场操作：

- 按原页面按钮逐步推进，适合跟随台词；
- 使用原系统内已有的阶段导航/按钮跳转，适合跳过某幕排练。

节点顺序遵循文档：A1、A2、A3、B1、B2、B3、B4、C1、C2、C3、C4、D1、D2、D3、D4。

## 语音策略

仅播放文档规定的短句：A1“画像已生成”、A3“全体科目达标”、B1“新警情”、B2“路线已推送”、B3“核验完成”、C1“已串并4起”、C3“异常停留，疑似藏匿”、C4“链条闭环”、D1“目标落单，建议盾棍”、D3“方案已推送”。

A2、B4、C2 保持静默。D2 的文档台词存在冲突，演示态提供统一画面，不自动播放冲突台词，待最终剧本确认后再启用。

所有音频使用本地 Microsoft Yaoyao WAV，预加载或首次进入页面时缓存；播放失败不阻塞画面，支持停止和重播。

## 稳定性边界

- 演示节点使用固定脱敏数据和本地状态机。
- 接口失败不影响演示画面；页面明确标注演示数据。
- 相同节点重复点击不会叠加多个播放器或重复动画。
- 页面切换、刷新、回到上一幕时清理旧定时器、音频和临时状态。
- 不模拟真实来电录音、真实身份核验结果或真实派警成功记录。

## 验收标准

1. 原系统默认打开后能进入演示态，左侧导航和原接处警页面仍存在。
2. A1 到 D4 可从原页面交互逐步演示，不依赖后端写入。
3. 文档规定的语音在对应节点播放一次，能停止和重播。
4. 快速重复点击、切换页面、接口离线时不白屏、不叠音、不残留动画。
5. 真实 API 和数据库无新增写入。
6. 通过类型检查、原页面回归测试和实际生产包渲染测试。
