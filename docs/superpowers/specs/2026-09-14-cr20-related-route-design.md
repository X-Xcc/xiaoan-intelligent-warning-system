# CR-20 关联点位褐色对比路线设计

## 目标

在 CR-20 的“关联点位”地图中增加一条褐色对比路线。原有蓝色路线保留；两条路线仅在第 3 个点位相交。地图右上角显示“路线重合率 5%”。

## 范围

- 只改“关联点位”地图 `ContactGaitMap`。
- 不修改“轨迹碰撞”工作区及其 68% 指标。
- 不改变点位顺序、点位选择、图片预览、底图加载和空状态行为。

## 数据与组件设计

1. 在 `lib/contact-case-map.ts` 中新增 CR-20 对比路线坐标和固定指标常量。
2. 对比路线使用与现有路线相同的本地地图坐标系。
3. 对比路线坐标必须包含第 3 个点位的锚点 `[640, 365]`，并通过不同的中间坐标避开第 1、2、4、5 个点位及原路线其他线段。
4. `ContactGaitMap` 在现有路线 SVG 中叠加褐色路线，并为两条路线提供清晰图例。
5. 在地图右上角增加紧凑的路线关系标注，文字为“路线重合率 5%”；通过 `aria-label` 暴露完整含义。
6. 褐色路线采用稳定的视觉样式，与蓝色路线有足够对比，但不改变点位按钮的颜色语义。

## 交互与兼容性

- 新路线仅为静态演示信息，不新增点击或编辑行为。
- 地图仍然在底图成功加载后绘制路线。
- 响应式布局下标注不得遮挡北向标记、点位标签或路线。
- 保留现有无障碍标签，并补充路线重合率语义。

## 验证

- 单元测试断言对比路线存在、包含第 3 个点位、并且重合率为 5%。
- 运行 dashboard 的构建命令，确认 TypeScript 与 Vite 构建通过。
- 通过浏览器打开 `/contact-review`，进入 CR-020 的关联点位，确认蓝色与褐色路线同时出现，唯一交点为 3 号点位，右上角显示 5%。

## 设计决策

路线数据放在地图模型文件中，而不是直接写在 JSX 里，便于保持坐标、点位和测试的边界清晰；样式继续复用现有 `contact-case-map.css` 体系，避免影响“轨迹碰撞”页面。
