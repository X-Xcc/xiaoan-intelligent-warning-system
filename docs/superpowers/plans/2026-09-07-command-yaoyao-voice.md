# 小安瑶瑶语音接入

用户已选定本机生成的瑶瑶音色。目标是在现有接处警页面接入固定音频，不调用云服务，不改变业务写入权限。

- [x] 用测试约束回执差异播报：首次加载、旧版本和切换事件不播历史状态；派警建议不等于已派警。
- [x] 新增纯函数语音映射，复用已生成的瑶瑶WAV。
- [x] 新增语音控制组件：用户启用、停止、重播、音量、字幕、错误提示。
- [x] 用同源Web Locks限制一个窗口出声；大屏不创建播放器。不支持锁时不启用自动播报。
- [x] 业务快照变化播报；回放仅按阶段播放教学台词，B4安静；切事件/账号/模式取消旧音频。
- [x] 执行语音测试、现有前端测试、Dashboard构建，更新交付说明。

语音启用不持久化，刷新后必须重新启用，防止自动发声。回放的B2/移交短句仅是教学台词，不表示调用业务接口。真实定位尚无独立确认契约，因此不自动播放“位置已确认”。

本轮不扩展备勤、研判、抓捕页面，不接ASR，不修改语音服务凭据，不自动提交Git。
