# 小安瑶瑶语音交付记录

日期：2026-09-07。用户试听后选择本机 Microsoft Yaoyao，使用已生成的固定 WAV，不需要语音服务密钥，不会把业务资料发送到外部合成服务。

> 后续同日已发布到服务器，新增HTTP协作播报兼容模式，不再因缺少Web Locks而禁止开启声音。公网入口、回退和正式验证结论见[服务器发布记录](小安接处警服务器发布记录-20260907.md)。下文单窗口锁描述针对HTTPS/localhost；HTTP为协作停止策略，不提供原子互斥。

## 入口与控制

使用桌面“小安接处警一键启动”，打开 `/command` 后，在工作区“小安 · 瑶瑶”处打开语音开关。提供暂停、继续、停止、重播、音量和字幕。默认关闭声音，刷新、切换账号或切换模式后需重新启用；切换事件保留启用状态，但停止旧语音、清空旧字幕及重播目标。

声音由控制工作台发出，大屏不创建播放器。同一浏览器、同一源使用 Web Locks 保证只有一个工作台取得播报权；另一个工作台开启时显示占用提示，不抢播。关闭语音或离开页面释放锁。不同浏览器、不同浏览器配置文件和不同源不共享此锁，不能保证互斥。

## 已接入节点

| 节点 | 瑶瑶台词 | 业务触发 |
|---|---|---|
| 新警情 | 小安提醒您，有新的警情。 | 队列同步新增待提交事件，首次同步静默 |
| 派警 | 派警指令已下达。 | 当前事件新增实际派警时间 |
| 签收 | 任务已签收。 | 当前事件状态变为已接收 |
| 到场 | 处警人员已到场。 | 当前事件状态变为已到达 |
| 核验 | 核验线索已返回，请人工复核。 | 产生新的核验记录 |
| 材料 | 现场材料已登记。 | 证据索引新增材料 |
| 移交提交 | 研判移交已提交。 | 移交记录进入已提交状态 |
| 移交接收 | 研判移交已接收。 | 移交记录进入已接收状态 |
| 现场完成 | 现场处置已完成。 | 事件公共状态变为已完成 |

语音只观察页面接收的授权快照，不写业务接口、不替代人工确认。首次加载、重复版本、旧版本及切换事件不播历史动作。外部更新随原有10秒轮询同步，不承诺实时到达或每个中间状态均播报。断线停止当前播报，重连建立新基线，不补读旧消息。

教学回放按照阶段切换：B1新警情、B2派警、B3核验、移交提交；B4清点静默，不盖住民警口述。同阶段展开卡片不重复播报；切回阶段可重新播放。台词旁标识“教学台词”，回放不会调用派警或移交接口。

真实模式暂不自动播放“位置已确认”：现有坐标不等于人工确认定位。未增加身份确定、犯罪认定、移交退回或处理开始台词，避免用不准确的既有音频代替。后续可扩充，但必须先制作对应台词和触发规则。
