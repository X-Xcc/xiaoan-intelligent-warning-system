# 公安平台一期框架实施计划

**目标：** 在现有 React/FastAPI 工程上形成可运行的公安大数据与AI平台统一门户框架。

**架构：** 新增公安平台门户页面，统一展示平台底座、AI能力中心和五个业务系统；保留现有指挥、视频、管理和勤务页面作为底层能力入口。运行指标优先绑定既有总览 API，尚未上报的业务能力显示待同步状态，并按数据目录和接口清单接入后续平台服务。

**技术栈：** React 19、TypeScript、Vite、Ant Design、Lucide React、现有 FastAPI API。

**基线文档：** `docs/公安大数据平台冻结交付方案.md`

## 实施任务

- [x] 冻结产品结构、一期范围和验收基线
- [x] 设计统一门户导航和平台总览信息架构
- [ ] 接入真实平台数据目录与主数据接口
- [ ] 接入一期业务系统工作台
- [ ] 补齐自动化测试、部署配置和现场验收材料

## 当前框架交互

统一门户提供：

- 平台运行总览：数据接入、实时事件、AI服务和业务闭环指标
- 平台底座：数据目录、主数据、GIS、实时事件和接口服务入口
- AI中心：模型服务、知识库、语音/视觉能力和审计状态
- 五大系统：训练、接处警、办案、社区、移动的入口卡片和一期功能清单
- 交付路线：阶段、周期、验收物和当前进度
