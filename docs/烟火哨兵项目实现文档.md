# 烟火哨兵项目实现文档

本文件记录烟火哨兵原型的当前实现结构，便于验收、交接和后续扩展。

## 1. 项目定位

烟火哨兵是一套面向夜市商圈、文旅街区和商业综合体周边夜间消费场景的安全治理原型。系统把群众端小程序、巡防端、Web 指挥后台和 FastAPI 后端串成一条闭环，用于风险发现、隐患上报、任务派单、现场处置和结果留痕。

## 2. 当前组成

- 群众端：`apps/miniprogram`
- 指挥后台：`apps/dashboard`
- 后端服务：`server`
- 专利与材料生成：`scripts/patent`
- 交付与说明材料：`docs`

## 3. 核心流程

1. 事件来源进入系统，包括群众上报、视频检测、巡防反馈和后台录入。
2. 后端进行事件归并、状态流转、证据帧保存和派单推荐。
3. 前端分别面向群众、巡防人员和指挥中心展示不同视图。
4. 事件结果写回事件库，并保留操作轨迹与审核痕迹。

## 4. 关键模块

- `server/app/services/event_store.py`：事件归并、统计、派单与状态视图。
- `server/app/services/security_detection.py`：视频检测结果接入与同步。
- `server/app/services/security_ai.py`：画面复核与结构化风险输出。
- `server/app/services/security_video.py`：视频相关接口与辅助逻辑。
- `server/app/api/routes/events.py`：事件接口。
- `apps/miniprogram/src/pages/main/main.tsx`：群众端主界面。
- `apps/dashboard/src/pages/DashboardApp.tsx`：指挥后台主界面。

## 5. 视觉与命名

当前项目统一使用“烟火哨兵”作为产品名，配套资源标识统一为 `yanhuo-shaobing`。页面、标题、图标和专利材料都沿用这一口径。

## 6. 验收要点

- 首页、详情页和后台页能正常打开。
- 事件列表、地图和派单视图可以联动展示。
- 专利材料能从当前代码和说明文档中回溯证据来源。
- 说明书附图保持黑白线条样式，便于提交。
