# 窗口 05｜集成、安全、性能与现场验收

## 目标

把前四个窗口的代码收口为可交付版本，验证接口、路由、业务流程、AI 责任链、权限边界、响应式和部署运行态。窗口 05 不新增业务功能，只负责发现问题、补回归测试和形成验收记录。

## 必用技能与工具

- `verification-before-completion`：所有“完成”结论必须有命令和结果。
- `code-review`：审查数据权限、AI 高风险动作、异常处理和依赖变更。
- `accessibility`：键盘、焦点、语义、对比度和窄屏检查。
- `web-perf`：在本地浏览器测量加载、布局稳定性和交互响应。
- `systematic-debugging`：遇到失败先定位根因，再做最小修复。
- 使用 agent-browser 或浏览器 MCP 做本地页面验收；禁止把公安数据发送到外部网站或公共模型。

## 执行步骤

### 1. 静态和编译验收

从 `D:\CICSIC` 执行：

```powershell
npm --workspace apps/dashboard run build
node --test scripts/verify_public_security_data_platform.mjs
node --test scripts/verify_platform_shell.mjs
node --test scripts/verify_police_workbench.mjs
node --test scripts/verify_police_platform_identity.mjs
& 'D:\CICSIC\server\.venv-runtime\Scripts\python.exe' -m compileall -q server/app
git diff --check
```

任何命令非 0 都要记录文件、行号、根因和修复窗口，不能用跳过测试代替修复。

### 2. 启动本地服务

先检查端口是否已被旧实例占用；不要直接终止未知进程。若 `8010` 已占用，使用 `8011` 作为后端端口，并在下面的检查命令中同步替换端口号。

```powershell
Get-NetTCPConnection -LocalPort 8010 -ErrorAction SilentlyContinue |
  Select-Object LocalAddress,LocalPort,OwningProcess,State
```

终端 A：

```powershell
& 'D:\CICSIC\server\.venv-runtime\Scripts\python.exe' -m uvicorn app.main:app --app-dir server --host 127.0.0.1 --port 8010
```

终端 B：

```powershell
npm --workspace apps/dashboard run dev -- --host 127.0.0.1 --port 5175
```

检查：

```powershell
Invoke-WebRequest http://127.0.0.1:8010/api/platform/overview | Select-Object -ExpandProperty StatusCode
Invoke-WebRequest http://127.0.0.1:5175/platform | Select-Object -ExpandProperty StatusCode
```

若后端改用 `8011`，对应检查命令为：

```powershell
Invoke-WebRequest http://127.0.0.1:8011/api/platform/overview | Select-Object -ExpandProperty StatusCode
```

### 3. 浏览器逐路由验收

逐一打开并记录结果：

```text
/platform   平台分层首页、数据域、AI中枢、业务入口
/command    接处警流程、摘要/分级人工确认
/case       案件流程、法律依据、证据和文书确认
/community  辖区画像、走访任务、风险闭环
/duty-plan  课程、模拟训练、评估报告、训练档案
/mobile     任务签收、身份核验、伴随指引、弱网回传
/ai-center  模型、Agent、Skill、MCP、AI责任链
/admin      数据目录、权限、审计和治理信息
```

### 4. 安全验收

- 检查所有 AI 写操作都经过业务 API 和人工确认。
- 检查日志不包含身份证号、完整报警录音、案件全文或模型密钥。
- 检查未授权用户无法读取跨辖区数据。
- 检查 MCP 连接器的 `scope` 与权限白名单一致。
- 检查接口异常时不泄露堆栈、路径或密钥。

### 5. 形成验收记录

新增 `docs/公安大数据AI平台窗口执行/验收记录.md`，每条记录包含：日期、环境、命令/路径、预期、实际、结果、截图或日志位置、责任窗口。

## 完成标准

- 所有静态、构建、编译和契约测试通过。
- 8 条核心路由可以加载，至少完成一次桌面和一次窄屏检查。
- 高风险 AI 建议、权限和审计检查没有未解释的阻断项。
- `验收记录.md` 完整，可供现场演示和合同验收引用。
