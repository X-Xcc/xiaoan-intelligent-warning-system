# 公安大数据与 AI 平台｜窗口执行包

按以下顺序打开新窗口并执行：

1. [00_窗口执行总控.md](./00_窗口执行总控.md)
2. [01_平台底座与数据资源中心.md](./01_平台底座与数据资源中心.md)
3. [02_AI智能中枢与智能体编排.md](./02_AI智能中枢与智能体编排.md)
4. [03_五大业务系统与统一事件链.md](./03_五大业务系统与统一事件链.md)
5. [04_Web统一门户与工作台.md](./04_Web统一门户与工作台.md)
6. [05_集成安全测试与现场验收.md](./05_集成安全测试与现场验收.md)

执行规则：

- 窗口 01 先冻结接口和数据对象；完成后窗口 02、03、04 可并行。
- 每个窗口只读取总控文档和自己的技术文档，不把整段聊天记录带入新窗口。
- 每个窗口只修改文档中列出的文件，并按总控文档的格式回传。
- 所有窗口完成后，由窗口 05 执行总验收命令并填写验收记录。

## 手动开窗方式

1. 在 `D:\CICSIC` 打开一个新任务，先粘贴 `00_窗口执行总控.md` 中的固定约束。
2. 再粘贴对应窗口文档末尾的“复制到新窗口的开工提示”。
3. 窗口 01 完成并回传契约后，再开启窗口 02、03、04；三者可以并行。
4. 将各窗口的变更保留在同一工作区，不需要复制整段对话；窗口 05 只读取文件和测试结果。

## 能力调用要求

- 每个窗口必须按文档中的“必用技能与工具”加载对应 Skill，并在开始时说明用途。
- 需要独立审查、契约检查或测试复核时，使用 Agent 分担一个边界清晰的子任务；主窗口负责合并判断。
- 需要官方 API、浏览器或本地运行态信息时，使用 MCP/本地工具获取证据；公安数据只在本地或内网范围处理。
- 技能、Agent、MCP 是执行手段，最终交付物仍是代码、接口、测试和验收记录。

## 窗口回传模板

```text
窗口：01/02/03/04/05
完成目标：一句话
变更文件：逐个列出绝对路径或仓库相对路径
新增接口/类型：列出名称和字段
测试命令：逐条列出
测试结果：PASS/FAIL，并附关键输出
未决项：没有则写“无”
```
