## AI、权限与审计

- AI 运行时 API 返回的结果包含置信度、依据和时间、回退动作、人工审核标识、审核状态和审计编号。
- 所有运行时 MCP 连接器都为只读（`writeAllowed: false`）：公安主数据目录 MCP 限组织/人员/地点/车辆，法律与类案知识库 MCP 限法条/判例/内部制度，统一事件链 MCP 限警情/案件/训练/移动。
- `POST /api/ai-center/review` 现要求 `Authorization: Bearer <token>`，未登录返回 `401`，无 `review` 权限返回 `403`；提交体中的 `operatorId` 不再被信任，审核人使用认证主体，成功审核写入 `ai.result.review` 系统审计。
- 未知审核编号返回 `404`，响应中未包含 `Traceback`、文件路径或密钥模式。
