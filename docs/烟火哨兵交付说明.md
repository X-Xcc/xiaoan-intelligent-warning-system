# 烟火哨兵交付说明

## 交付范围

- 群众端小程序：微信登录、求助、隐患上报、失物/线索登记、进度查询、个人页。
- 巡防人员端：任务接收、到场、处置、记录、地图和台账。
- Web 指挥后台：运行总览、事件工单、报警推送、视频监控、复核状态。
- 后端服务：事件接口、报警推送、实时通道、视频与画面复核接入。

## 现场验收重点

1. 群众端能完成微信登录并提交求助。
2. 指挥端能看到同一条事件进入报警队列。
3. 巡防端能接单、到场、处理、回填结果。
4. 视频检测结果能同步成事件工单。
5. 大屏、后台和小程序读取同一套事件数据。

## 部署准备

- Node.js 22 或兼容版本。
- Python 3.11。
- PostgreSQL 数据库。
- 微信开发者工具。
- 生产环境使用 HTTPS 和真实域名。

## 必要环境变量

```powershell
$env:DATABASE_URL="postgresql://user:password@host:5432/yanhuo_shaobing"
$env:WECHAT_APPID="你的微信小程序 AppID"
$env:WECHAT_APP_SECRET="你的微信小程序 AppSecret"
$env:TARO_APP_API_BASE_URL="https://你的域名/api"
$env:SECURITY_VIDEO_BASE_URL="http://127.0.0.1:5000"
$env:SECURITY_VLM_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1"
$env:SECURITY_VLM_API_KEY="你的画面复核密钥"
$env:SECURITY_VLM_MODEL="qwen-vl-plus"
```

## 验收命令

```powershell
npm run dashboard:build
npm run miniprogram:build:weapp
npm run miniprogram:build:alipay
py -3 scripts\verify_delivery.py
```

## 交付约定

- 小程序前端不保存 AppSecret。
- 密钥只放后端环境变量，不写进前端代码。
- 本地测试与生产配置分开管理。
- 交付前先完成数据库备份与接口健康检查。
