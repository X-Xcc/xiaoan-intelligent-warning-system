# 备勤训练试点训练工作台与验收

## 1. 页面映射

| 区域 | 页面行为 | 数据接口 |
|---|---|---|
| A1 勤务态势 | 风险组成、依据、规则版本、更新时间、样例边界 | `GET /api/training/readiness` |
| A2 靶向训练 | 三张任务卡；查看装备、标准；开始、完成、异常登记、显示状态 | `GET /api/training/tasks`、`POST .../start`、`POST .../complete`、`POST .../exception` |
| A3 AI 动捕考核 | 左侧监控画面；开始本地录像；结束后小安评分、文字/语音评价；摄像头异常可用 `Tab + P` 快捷评分；三项分数、总分、置信度、证据时间、审计号、复核入口 | `POST .../assessment`、`POST /api/training/assessments/{id}/review` |
| T1 训练档案 | 结果、薄弱项、补训建议、档案审计号；按档案创建补训任务 | `GET /api/training/archives`、`POST /api/training/archives/{recordId}/retraining` |

## 2. 交互状态

- 加载：显示“正在同步脱敏训练样例”。
- 接口不可用：保留本地工作台，不伪造在线状态。
- 任务状态：`待训练`、`训练中`、`待复核`、`已归档`、`待复训`。
- 评分状态：`pending` 时显示人工复核入口；确认后显示审计编号和档案结果。
- 录像状态：`待机`、`LIVE 本地录像中`、`录像回放`；原始录像仅保留在浏览器本地，不上传训练接口。
- 小安评价：评分接口返回后生成文字评价并尝试浏览器语音播报；失败时保留文字评价。
- 快捷评分：按 `Tab` 后在 1.2 秒内按 `P`，或点击“快捷评分 Tab + P”，仅对当前 `训练中` 任务生效。
- 任何 AI 建议旁边都显示依据、时间和“仅供人工确认”边界。

## 3. 验收用例

| 编号 | 操作 | 通过条件 |
|---|---|---|
| A1-01 | 打开 `/duty-plan` | 看到样例边界、规则版本和至少 3 条推荐依据 |
| A2-01 | 查看任务清单 | 看到 3 个科目、装备、达标标准和状态 |
| A2-02 | 开始并完成一项任务 | 状态依次为 `训练中`、`待复核`，记录用时 |
| A2-03 | 对任一任务登记异常 | 保存异常原因、登记人、时间和异常审计编号；不自动改变评分结论 |
| A3-01 | 点击“开始录像” | 浏览器请求摄像头权限；画面显示 `LIVE 本地录像中`、计时和脱敏水印；录像不上传 |
| A3-02 | 点击“结束并由小安评分” | 停止录像并生成本地回放；三项分数、总分、置信度、证据、规则版本、审计号和小安评价齐全 |
| A3-03 | 摄像头不可用时按 `Tab + P` | 触发同一评分接口并显示文字/语音评价，不改变人工复核边界 |
| A3-04 | 教官确认 | 评分变为 `confirmed`，任务变为 `已归档` |
| T1-01 | 查看档案 | 有结果、薄弱项和补训建议，可追溯任务与评分 |
| T1-02 | 点击“创建补训任务” | 生成 `待训练` 补训任务，继承科目/标准并保留来源档案引用 |
| SAFE-01 | 未授权 AI 自动决策 | 系统无自动改变业务状态的路径 |

## 4. 现场联排顺序

1. 刷新页面，确认 A1 快照时间和规则版本。
2. 在 A2 选择一项任务，点击“开始训练”，再点击“完成并评分”。
3. 在 A3 核对三项分数、置信度、证据时间和审计编号。
4. 进入“训练档案”，完成教官确认，核对补训建议并创建补训任务。
5. 断开 API 重载页面，确认降级文案出现且不显示虚假的在线结果。
