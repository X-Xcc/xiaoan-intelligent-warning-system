# 备勤训练试点训练数据与规则

## 1. 数据边界

首期只使用脱敏样例，不接入真实身份证号、完整报警录音、案件全文、原始人脸素材或模型密钥。接口统一返回 `dataMode=desensitized_sample`，页面必须显示该标识。

## 2. A1 态势快照

| 字段 | 类型 | 说明 |
|---|---|---|
| `dataMode` | string | 固定为 `desensitized_sample` |
| `updatedAt` | ISO datetime | 快照生成时间 |
| `ruleVersion` | string | 当前规则版本，如 `READINESS-RULE-2026.09-V1` |
| `riskComposition` | array | 风险类型、占比、展示色调 |
| `heatZones` | array | 区域、等级、依据 |
| `timeTrend` | array | 时段与风险值 |
| `recommendations` | array | 训练科目、任务主键、依据、达标标准 |
| `notice` | string | 样例态势边界声明 |

## 3. 训练科目与达标标准

| taskId | 科目 | 装备 | 首期达标值 | 推荐依据 |
|---|---|---|---|---|
| `TRAIN-READINESS-001` | 单警装备快速取用 | 执勤腰带、对讲机、执法记录仪 | 30 秒内取用完毕 | 高峰时段警情响应用时波动 |
| `TRAIN-READINESS-002` | 弱光队形转换 | 照明设备、对讲机、反光标识 | 10 秒内完成转换 | 弱光区域风险占比较高 |
| `TRAIN-READINESS-003` | 防爆警戒圈设置 | 警戒带、反光锥、扩音器 | 30 米警戒圈 60 秒内设定 | 聚集类风险处置复盘 |

## 4. 状态机

```text
待训练 -> 训练中 -> 待复核 -> 已归档
                         └-> 待复训（教官驳回或低分）
已归档 -> 创建补训任务 -> 待训练（保留来源档案引用）
```

开训记录 `startedAt`，完训记录 `elapsedSeconds` 与 `completedAt`。异常登记必须记录原因、登记人、时间和异常审计编号；异常本身不自动改变评分或档案结论。未经评分和教官复核，不得写入训练档案。

## 5. 规则变更

达标值、科目、装备或推荐依据发生变化时，必须提升 `ruleVersion`，同步修改本文件、评分文件和验收用例；不得静默替换样例口径。
