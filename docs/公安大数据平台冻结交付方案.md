# 公安大数据与AI平台冻结交付方案

**版本：V1.0（2026年9月4日冻结）**

## 1. 交付结论

交付一套可私有化部署的公安大数据与AI平台，固定由统一门户、公安大数据底座、AI能力中心、统一支撑能力和五个业务系统组成。

现有 React/FastAPI 工程作为技术底座复用；产品导航、主数据、业务流程和验收材料按公安平台重新定义。

## 2. 固定产品结构

1. 统一门户与工作台
2. 公安大数据平台
3. AI能力中心
4. 勤务训练系统
5. 接处警系统
6. 执法办案系统
7. 社区警务系统
8. 移动勤务系统
9. 统一权限、流程、消息、审计与运维

## 3. 一期冻结范围

### 平台底座

- 统一身份、组织、角色和数据权限
- 人员、组织、地点、车辆、警情、案件、证据、训练档案、任务主数据
- 数据目录、接口目录、GIS地图、实时事件中心
- API网关、消息通知、操作审计、配置管理
- 内网模型服务、知识库检索、语音转写、文档抽取

### 业务闭环

```text
接警 → 分类分级 → 派警 → 移动签收 → 现场处置 → 案件/证据 → 社区风险更新 → 训练复盘
```

### 一期业务功能

| 系统 | 一期功能 |
|---|---|
| 勤务训练 | 训练计划、1—3个模拟场景、评分报告、训练档案 |
| 接处警 | 语音转写、摘要警单、分类分级、派警建议、问询提示 |
| 执法办案 | 法律问答、取证清单、带依据的文书草稿 |
| 社区警务 | 辖区画像、走访任务、隐患闭环、警情聚合热力 |
| 移动勤务 | 工作台、任务签收、现场指引、移动问答、结果回传、弱网缓存 |

## 4. 后续扩展范围

MR课程编辑器、39种完整模拟场景、100余条反诈案例、体能芯片、个性化训练推送、证据规则全量校验、类案与串并案分析、身份与车牌核验、AI眼镜、检法跨部门协同，按照数据、设备、协议和安全条件分批上线。

## 5. 统一AI结果规范

所有智能结果必须返回：结果、置信度、依据/数据时间、解释要点、人工确认入口、回退操作和审计编号。AI只提供辅助建议，不替代接警确认、案件审批、签发和执法决定。

## 6. 实施阶段

| 阶段 | 周期 | 主要交付物 |
|---|---:|---|
| 需求与现状盘点 | 4周 | 需求规格、数据/接口清单、总体架构、试点方案 |
| 平台底座 | 8—12周 | 数据治理、权限、接口、模型服务、安全与容灾 |
| 一期样板 | 12—16周 | 五系统样板、集成测试、UAT、培训材料 |
| 试点运行 | 8—12周 | 双轨运行报告、指标对比、上线评审 |
| 分批推广 | 3—6个月 | 波次部署、迁移校验、运维SLA、最终验收 |

## 7. 验收基线

- 核心API可用性不低于99.5%，核心服务月可用性不低于99.9%
- P95查询响应不高于2秒，实时链路延迟不高于60秒
- 高危漏洞上线前为0，特权操作审计覆盖率100%
- 警情分类宏平均F1建议不低于0.90，派警Top-1命中率建议不低于90%
- 摘要必填字段完整率建议不低于95%，法律/类案检索结果必须带出处
- 训练报告生成时间建议不超过5分钟，动作识别计数误差建议不超过5%
- 最终阈值以双方确认的黄金测试集和合同验收条款为准

## 8. 固定决策

本项目采用“复用技术底座、重构公安产品”的路线；一期先做平台底座和可验收业务闭环，再扩展高级AI、硬件和跨部门协同能力。该结构作为后续原型、开发、测试、部署和验收的唯一基线。
