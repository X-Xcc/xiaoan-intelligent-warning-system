# PPT 技术呈现链路基线

日期：2026-09-28

这份基线记录当前系统在继续改造前已经具备的能力，作为后续“AI 初筛 → 复核 → 风险分级 → 派单 → 处置归档”演示链路的起点。

## 当前仓库状态

- 默认分支：`main`
- 当前基线提交：`185adf8`
- 前端：React + Vite，位于 `apps/dashboard`
- 后端：FastAPI，位于 `server`
- 移动端：微信小程序，位于 `apps/miniprogram`
- 检测与设备桥接：位于 `integrations` 及相关服务目录

## 已有的指挥流程骨架

现有指挥台支持以下可回放或联调阶段：

1. B1 接警登记
2. B2 风险摘要与关联事件确认
3. B3 路线预览与派单确认
4. B4 到达、处理中、完成及证据上传
5. 研判移交、审核与审计记录

`playback`、`rehearsal` 和 `surface=display` 模式可以把同一个事件编号贯穿在控制台与大屏展示中。

## 下一步改造边界

下一阶段在保留上述事件状态机的基础上，增加统一的 AI 处理链对象，并在页面中连续呈现：

```text
现场画面 / 小程序报警
  → 事件编号生成
  → YOLO 初筛
  → 人工或二次复核
  → 风险分级
  → 路线与警力推荐
  → 人工确认派单
  → 到达 / 处理中 / 已完成
  → 证据上传与复盘归档
```

当前展示应明确区分“本地已验证”“模块试用”和“待联调/待实测”，避免把演示数据误读为完整生产闭环。

这份文档只记录基线，不改变运行时行为；后续功能修改应在独立提交中完成并通过前端构建与后端命令流程测试。
