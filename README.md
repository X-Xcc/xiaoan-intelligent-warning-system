# 小安智能预警系统

这是小安智能预警系统的完整 Windows 原生部署仓库。它不需要 Docker Desktop。系统会在目标 Windows 电脑上分别启动 PostgreSQL、后端 API、管理网页和视频检测服务。

> 本版本已取消项目内登录、管理令牌和角色访问限制，所有能连接服务的人都可以访问及操作功能。接处警及 AI 审核以 `open-access` 公共身份留痕，免登录审计不能用于识别真实操作者。请勿将服务暴露到公网；设备密码、第三方服务密钥和浏览器摄像头权限仍然需要。

当前电脑应用已构建的免登录更新：右键 `apply-open-access.cmd`，选择“以管理员身份运行”。脚本会校验待更新文件和进程，替换检测服务并重启，不删除业务数据。Windows 管理员权限用于读取原有加密设备目录，与项目登录无关；更新前已停止的摄像头需在设备页面重新连接。此脚本需要本机已准备好的暂存构建，不适用于刚下载的源码目录。

> 代码仓库只保存可公开部署的程序与脚本。真实业务数据、设备账号、图片视频、模型训练材料和登录密钥都在单独的加密迁移包中，绝不能上传到 GitHub。

## 这套部署会带来什么

使用与本次代码版本配套的 `.xiaoan` 加密迁移包恢复后，目标电脑会获得：

- 小安管理网页、指挥调度、事件工单、预警、巡查、培训和后台管理功能。
- PostgreSQL 中的业务表、历史记录和配置。
- 已导出的证据图片/视频、设备桥接加密配置、检测结果和检测服务数据。
- YOLO 模型、检测服务配置、训练数据集和训练结果（以迁移包实际包含的内容为准）。
- Java 检测服务、Python YOLO 检测入口、go2rtc 转流程序与网页前端的原生启动脚本。

恢复程序会在启动前校验数据库表及行数，并逐个计算私有文件的 SHA-256；任何一项不一致都会停止，不会把“恢复了一部分”说成成功。

## 开始前，请准备好

1. 一台 64 位 Windows 10 或 Windows 11 电脑，建议有管理员权限、16 GB 内存和至少 35 GB 可用磁盘空间。
2. 能联网的环境。首次安装会下载 Python、Java、PostgreSQL、Node.js 及项目依赖。
3. 从 GitHub 下载的完整代码文件夹，例如 `D:\XiaoAn`。不要直接在旧系统目录上覆盖安装。
4. 单独收到的两个私有文件：
   - `*.xiaoan`：加密迁移包。
   - `*.transfer-key`：与该包配对的密钥文件。
5. 迁移包和密钥放在不同位置，例如迁移包放在 `E:\XiaoAnTransfer`，密钥放在受控 U 盘或密码库导出的临时位置。

不要把密钥重命名为迁移包、不要把两者压进同一个公开压缩包、不要把它们放进项目文件夹，更不要提交到 GitHub、网盘公共链接或聊天群。

## 给新手的完整恢复步骤

以下步骤适用于“另一台电脑要完整复制当前系统”的情况。第一次请按顺序做完，不要跳步。

### 第 1 步：下载并解压代码

1. 打开 GitHub 仓库页面，点击绿色的 **Code** 按钮。
2. 点击 **Download ZIP**。
3. 找到下载的 ZIP 文件，右键选择 **全部提取**。
4. 将解压后的文件夹移动到一个新的位置，例如 `D:\XiaoAn`。
5. 打开该文件夹，确认能看到 `README.md`、`start.cmd`、`restore.cmd`、`install-prerequisites.cmd`、`apps`、`server`、`deploy` 和 `integrations`。

目标文件夹必须是新建的、没有恢复过系统的文件夹。若里面已有 `deploy\native\.env`、`deploy\native\data` 或已有业务数据，请换一个全新的文件夹重新解压代码。

### 第 2 步：安装运行环境

1. 在项目根目录双击 `install-prerequisites.cmd`。
2. Windows 可能会询问是否允许安装程序更改设备，选择 **是**。
3. 等待脚本检查或安装 Python 3.12、Java 21、PostgreSQL 18，并下载 Node.js 22 运行时。
4. 看到“Prerequisite installers were started or completed”后，关闭这个黑色窗口。
5. 重新打开项目文件夹。

如果这一步已经下载了 Node.js，那么项目里的 `deploy\native\.runtime\node` 是正常的安装依赖，不是业务数据。新版 `restore.cmd` 会保留它并继续恢复。

如果电脑没有 `winget`，请让电脑管理员安装下列官方软件后再双击一次 `install-prerequisites.cmd`：Python 3.12、Eclipse Temurin JDK 21、PostgreSQL 18。Node.js 会由项目脚本下载，不需要单独找版本。

### 第 3 步：恢复完整业务副本

1. 确认迁移包和密钥都已经在本机，但都不在项目文件夹内。
2. 在项目根目录双击 `restore.cmd`。
3. 第一个选择窗口中选中 `.xiaoan` 加密迁移包。
4. 第二个选择窗口中选中与之配对的 `.transfer-key` 密钥文件。
5. 保持窗口打开，等待恢复、校验、构建和启动完成。5 GB 级迁移包和首次依赖下载通常需要较长时间。
6. 看到 `Restore verification passed` 以及 `READY: http://127.0.0.1:8080` 后，打开浏览器访问 `http://127.0.0.1:8080`。

恢复脚本会创建独立的 PostgreSQL 数据目录，恢复数据库、恢复文件、核对全部文件哈希、核对表/行数、初始化本机专用账号，并配置检测服务向本机 API 上报。它不会覆盖已经存在的目标数据；出现错误时保留现场，使用新的代码文件夹重试，不要删除旧数据硬重来。

### 第 4 步：日常开机和关机

- 日常启动：双击根目录的 **`一键启动.cmd`**（或 `start.cmd`）。脚本依次检查环境、启动数据库、API、检测服务和管理网页，全部就绪后自动打开浏览器。
- 停止系统：双击 **`一键停止.cmd`**（或 `stop.cmd`）。这只停止本项目启动的进程，保留数据库和恢复的数据。
- 检测控制台：浏览器访问 `http://127.0.0.1:5000`。

首次启动可能需要下载依赖，请等待进度提示；启动失败时窗口会保留错误信息，并显示日志目录。若浏览器未自动打开，可手动访问 `http://127.0.0.1:8080`。后台服务不弹出额外终端窗口，关闭网页不会停止服务。

系统默认只监听本机回环地址：网页 `8080`、API `8010`、检测服务 `5000`、数据库 `5433`。这样新部署不会意外暴露到公网。

### 第 5 步：确认网页、API 和检测服务

恢复或启动完成后，在浏览器依次打开：

1. `http://127.0.0.1:8080`：小安管理网页。
2. `http://127.0.0.1:8010/api/health/ready`：应返回包含 `"status":"ready"` 的 JSON。
3. `http://127.0.0.1:5000/api/detection/status`：检测服务状态。

三个地址都能打开，才表示本机的网页、API 和检测服务都已启动。业务账号报告只保存在恢复脚本输出的私有目录中；不要把报告截图、复制到共享文件夹或上传到 GitHub。

## 摄像头和硬件：默认不会自动连接

为避免新电脑一恢复就连接真实摄像头、机器人或 USB 设备，`restore.cmd` 与 `start.cmd` 默认只恢复配置，不启动采集和转流。

在确认目标电脑接入了正确的受控网络、设备授权也符合要求后，双击 `enable-cameras.cmd`。它会先停止当前服务，再重新启动设备桥接、检测采集和 go2rtc。设备网络、摄像头密码、USB 驱动和硬件型号必须在目标电脑上单独验收。

## 如果只是安装一个空白新系统

没有业务迁移包时，不要运行 `restore.cmd`。在新的代码文件夹中双击 `start.cmd` 即可创建一个新的本机数据库、生成新的私有部署配置并启动空白系统。它不会包含原电脑的历史业务数据、设备配置或账号。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| `install-prerequisites.cmd` 提示缺少软件 | 按窗口提示安装 Python 3.12、Java 21 或 PostgreSQL 18；安装后关闭窗口，再重新双击。 |
| `restore.cmd` 说目标目录已有数据 | 如果目录里只有 `deploy\native\.runtime\node`，请下载 GitHub 最新版本后重新运行；新版会保留这个正常的 Node.js 运行时。如果还有 `data`、`logs`、`run`、数据库或虚拟环境等内容，请重新下载并解压一份代码到新的空文件夹。 |
| 恢复校验失败 | 保留迁移包、密钥和错误窗口，检查磁盘空间、迁移包是否完整、密钥是否配对。不要换用其他来源的密钥。 |
| 网页打不开 | 先双击 `start.cmd`，再确认 `http://127.0.0.1:8010/api/health/ready` 是否可访问。日志在 `deploy\native\logs`。 |
| 检测服务启动失败 | 先确保 Java 21 已安装。首次构建会下载 Maven 依赖，网络中断后重新双击 `start.cmd`。 |
| 摄像头没有画面 | 这是默认保护行为。先检查网络、驱动和设备授权，再双击 `enable-cameras.cmd`。 |

## 不能靠文件自动复制的内容

迁移包可以校验和恢复软件、数据库、文件、模型及已导出的配置，但不能替目标电脑自动完成以下事项：摄像头/机器人/USB 驱动安装，局域网连通性，设备厂商授权，微信或支付宝平台凭据，地图和 AI 服务额度，公网 HTTPS 配置，以及源端本来就不存在的本地大模型。上述项目需要在新电脑和对应平台上逐项验证。

详细的恢复边界、目录说明、运维和验收清单见 [完整部署说明](docs/deployment-full-replica.md)。
